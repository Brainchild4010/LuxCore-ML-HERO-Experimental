# LuxCore ML HERO Experimental

Experimental modification of LuxCoreRender 2.11.1.

This repository contains development and research work around:

- ML HERO spectral dispersion
- HERO Sampling 1.0 - Linear
- HERO Sampling 2.0 - CIE Weighted
- HERO Sampling 3.0 - Sensor Weighted
- Fine RoughGlass experiments
- CPU Path / Bidir / CUDA / OpenCL spectral extensions
- Future Sellmeier dispersion model

## Status

Experimental / Work in Progress
